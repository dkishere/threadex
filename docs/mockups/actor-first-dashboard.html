Actor-first dashboard redesign

IrisRunning 12m
Steer this task…

Hierarchy

  • Actors are the primary unit: avatar, character name, role (roleSummary), model, and one status cluster.
  • Order: needs-you actors → running → idle with recent completions → idle actors folded into one quiet row.
  • Workspace pulse (running / needs you / conclusions / done) and the token sparkline replace the large chart.

Session block

  • Compact: status dot, title, elapsed time, Stop (running only), and a disclosure button.
  • Pointer hover (0.25s delay) shows a floating peek, so the list doesn't shift.
  • The disclosure button (aria-expanded) pins details inline. Keyboard and touch use it, so nothing is hover-only.
  • Details keep every existing field: metrics, request, queued prompts with Fork, comments and Loop.

Flows kept as they are

  • Claim and task chips under actor replies open the session in the dashboard slot; Close returns to the dashboard.
  • The session header gains the owning actor chip. Execution semantics are unchanged.
  • Sessions without an owning actor stay visible under “Not owned by an actor”.
  • Narrow widths keep the Chat / Dashboard tabs.
